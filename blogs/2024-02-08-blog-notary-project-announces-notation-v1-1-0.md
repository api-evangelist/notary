The Notary Project maintainers are proud to announce new releases for its sub-projects, including Notary Project specifications v1.1.0 , notation v1.1.0 , notation-go v1.1.0 , and notation-core-go v1.0.2 , Notation GitHub Actions v1.0.1 which are ready for production use! Meanwhile, a new library notation-plugin-framework-go released the first release v1.0.0. It contains framework required to create notation plugins as per Notation Plugin specification .
