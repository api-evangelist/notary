The Notation maintainers are pleased to announce the release of Notation v1.0.0-RC.7, including Notation CLI v1.0.0-rc.7 , notation-go library v1.0.0-rc.6 , and notation-core-go library v1.0.0-rc.4 . This blog walks you through the updates in this release. NOTE: Both Notation CLI v1.0.0-rc.7 and v1.0.0-rc.6 have the same functionalities.
