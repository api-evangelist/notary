The notation CLI uses the following directories for its binaries and configuration files: NOTATION_BIN is the directory for the notation binary. NOTATION_LIBEXEC is the directory for other binaries, such as plugins, used by the notation . NOTATION_CONFIG is the directory for the configuration files, including trust stores and trust policies.
